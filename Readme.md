🚀 The Mission
I am building the core engine of an Instagram-like platform. The goal is to handle complex relationships, media storage, and real-time interactions while maintaining high performance.
---

🛠 Tech Stack
Language: Java

Framework: Spring Boot

Database: SQL (Managed via MySQL Workbench)

Status: 🏗️ Work in Progress
---

🧠 Evolution & Learning
This isn't a "finished" project—it’s a daily journey.

I am adding new concepts every day (JPA/Hibernate, Security, REST APIs).

The codebase evolves as I learn better ways to architect systems.
---

🎨 Frontend Help Wanted!
Currently, I am focusing 100% on the Backend logic.

Note: There is no frontend for this project yet. If you are a frontend developer looking to hook up a React, Angular, or Vue app to a solid Spring Boot API, I'd love to collaborate! Please reach out or open a PR.

🛠 How to Run (Local)
Clone the repo: git clone <your-link>

Setup your SQL schema using MySQL Workbench.

Update application.properties with your DB credentials.

Run ./mvnw spring-boot:run
